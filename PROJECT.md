# Easter Skies

- common/: shared upstream implementation and resources.
- fabric/: Fabric entrypoints, metadata and platform adapter.
- forge/: upstream Forge variant; target household stack is Fabric.
- gradle.properties: honest baseline/dependency pins and Easter artifact branding.
- LICENSE, COPYING (where applicable), EASTER_CREDITS.md: notices to preserve.
- FORK_PROVENANCE.json: exact source import and license checksum.
- check_fork.py: branding, provenance and resource-notice verification.

The complete cross-project design is EASTER_FLEET.md in Easter Skies.
This project is a source foundation, not a deployed Minecraft 26.2 mod.
